What is actually established?

A sender reports an act. The original author makes a distinct, local decision about that report. Both records can be exchanged, independently preserved, disputed, and inspected. This is not authenticated identity, a verified beneficiary outcome, a payment, a donation, or a Full Measure deed.

No automatic syncing. No public publication. No background action. A report is not proof; a local confirmation is not global truth.

WHAT THE PROOF DOES NOT CLAIM

Integrity is not identity.

A deterministic hash chain detects changed data if you retain a trusted earlier head to compare against. An attacker controlling an unsigned local file can rewrite the full chain.

Thus the experiment proves replay, local consent separation, and byte-level tamper detection against an unchanged receipt. It does not prove human authorship, authenticity, real-world deeds, cryptographic signatures, or sybil resistance.

A claim can be honestly preserved and still be false. A refusal can be preserved without erasing the claim.
