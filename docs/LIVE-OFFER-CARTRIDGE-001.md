# LIVE OFFER 001 — proposed reLATTE cartridge (not a crossing)

A source-owned, declarative possibility for composing optional `NOW -> WHAT -> HOW -> RETURN` actions. This v0 specimen is explicitly **not** an admitted reLATTE organ contract, signed crossing, capability, public authorization or receipt. It lives in `cartridges/live-offer-001.json`; `owner` names webZ, while reLATTE preserves the specimen without acquiring the donor's authority.

Cartridge data contains words-to-domain patterns, accepted local actions, output kinds, prerequisites and possible follow-on steps. Deterministic engines can rank actions without running them. Actual actions remain source-owned and explicitly user-triggered. Current verified browser implementation is in `the-static-collective/webZ/jubilee/live/`; JAR;VIS has an independent CLI consumer in `the-static-collective/JAR-VIS/tools/live-offer.mjs`.

**Truth boundaries:** `NOW_IS_PROPOSED_NOT_ASSUMED`; an offer does not grant recording permission or human authority; recording does not upload; a private receipt does not confirm a booking. Stream hosting, real-time matchmaking, AI artwork and unattended learning are **not supplied** by this cartridge. The engine's limited learning is opt-in action preference counts, not trained semantic intelligence.

No signature or content address is attributed to this file. If later transported as an opaque organ crossing, source must produce signed reLATTE payload refs and receiving worlds must independently HOLD/ADMIT/REFUSE under the existing contract. No donor code may bypass the receiver.
