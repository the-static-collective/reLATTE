# FIELD CONSEQUENCE 001

**Status:** bounded executable R9 witness  
**Date:** 2026-10-01

## Thesis

Admitted local history may alter a derived field of susceptibility without the field becoming history, truth, authority, or recommendation.

```text
ADMITTED LOCAL RECEIPTS
          +
SIGNED R8 PERSPECTIVES
          ↓
     TYPED FEATURES
          ↓
    OWNER-LOCAL LENS
          ↓
      FIELD / WEATHER
```

The lens belongs to the world.

reLATTE does not universalize its weights.

## Typed features

R9 extracts only structural, verifiable features:

- admitted receipt count;
- admitted descendant count;
- perspective receipt count;
- distinct observer count;
- plural-perspective excess per Moment;
- explicit uncertainty-item count.

No natural-language truth scoring is performed.

```text
FEATURE != VERDICT
COUNT != VALUE
```

## Field lens

A Field Lens names susceptibility channels and integer weights over typed features.

Example:

```text
continuation:
  admitted_receipts × 2
  admitted_descendants × 1

plurality:
  perspective_receipts × 1
  distinct_observers × 1
  plural_perspective_excess × 3

ambiguity:
  uncertainty_items × 1
```

The weights are owner-local.

Another world may use another lens.

```text
LENS != HISTORY
LOCAL WEIGHT != UNIVERSAL VALUE
```

## History root

Before applying a lens, R9 creates a deterministic history root over the sorted IDs of:

- admitted R3 receipts;
- R8 Perspective receipts;
- referenced Moments.

The history root does not contain lens weights.

Therefore two different lenses over the same admitted/witness history produce:

```text
same history_root
different lens_id
different projection_id
possibly different susceptibility
```

This is intentional.

> **WEATHER MAY DIFFER WHILE HISTORY REMAINS THE SAME.**

## Susceptibility

A projection exposes named numeric channels only.

It does not expose:

- authorization;
- capability;
- winner;
- truth score;
- ranking;
- recommended action.

Every projection fixes:

```text
semantic_effect = none
authorization = null
recommended_action = null
```

```text
SUSCEPTIBILITY != INSTRUCTION
WEATHER != RECOMMENDATION
WEATHER != AUTHORITY
```

## Admission boundary

Only signed `R3_ADMIT` receipts from the lens's own world may enter admitted history.

R3 REFUSE / HOLD / RETURN receipts do not count as admitted consequence.

R8 Perspectives may contribute only when their Moment anchors a crossing present in that admitted history.

So an account about an unadmitted crossing cannot affect this local field.

```text
OBSERVED ELSEWHERE != ADMITTED HERE
PERSPECTIVE != ADMISSION
```

## Plural witness

R8 accounts contribute structurally.

R9 can observe:

- how many perspectives exist;
- how many distinct observers signed;
- how many extra perspectives share a Moment;
- how many uncertainty items were explicitly recorded.

It does not decide which Perspective is correct.

```text
PLURALITY != VOTE
UNCERTAINTY COUNT != TRUTH PROBABILITY
```

## Determinism

Receipt and Perspective IDs are sorted before the history root is computed.

Reordering identical inputs produces the same:

- history root;
- feature vector;
- susceptibility;
- projection ID.

## Non-authority proof

The executable test proves a Field Projection:

- is not a reLATTE receipt;
- is not a crossing;
- cannot be passed to a Local Receiver as if it were a crossing;
- has no capability reference;
- has no authorization;
- has no recommendation;
- has no semantic effect.

Changing projected susceptibility after addressing invalidates projection verification.

## What this earns

At the current envelope level, this satisfies R9:

- admitted history alters susceptibility;
- plural witness can alter the derived field;
- field projection does not rewrite source receipts or Moments;
- different local lenses can produce different weather over the same history root;
- weather cannot authorize an action.

## What it does not earn

This does not claim:

- predictive validity;
- objective social measurement;
- ranking;
- recommendation;
- automated governance;
- causal inference;
- emotional-state inference;
- truth adjudication;
- R10 descendant semantics.
