## 1. Grammar Diving Bell

The Diving Bell takes an observed seam and emits a **candidate grammar**.

Required fields include:

- where the seam was observed;
- evidence references;
- a portable proposition;
- operators;
- explicit non-authorities.

Its output is always:

```text
status = CANDIDATE
```

It cannot establish endorsement, ownership, identity, or local authority.

```text
OBSERVATION != GRAMMAR
GRAMMAR CANDIDATE != TRUTH
RESEMBLANCE != ANCESTRY
SOURCE PERSON != EXECUTABLE PERSON
```

This is the Pirate Dock / SEAMforge / National Treasure composition surface.

## 2. Postal Service

A signed reLATTE crossing may travel by several carriers without changing crossing identity.

The first executable carriers are named as:

- `git-artifact`
- `file-bundle`
- `http-relay`
- `removable-media`

The carrier packet repeats the crossing ID and carries the original signed crossing.

Verification requires:

1. packet crossing ID equals contained crossing ID;
2. contained signed crossing verifies.

```text
CARRIER != CROSSING
TRANSPORT != AUTHORITY
TRANSPORT CHANGE != SEMANTIC MUTATION
```

This is the seed of the podcast-by-mail / creative-postal-service idea and a pressure path toward R6.

## 3. Front Door

Front Door composes:

```text
PORCH
  ↓
CUSTOMS
  ↓
WELCOME?
  ↓ yes
LOCAL DISPOSITION
```

A customs HOLD or REFUSE stops before local admission.

A customs WELCOME merely permits the crossing to reach local decision.

The executable witness proves:

```text
CUSTOMS_WELCOME → COM5_ADMIT
CUSTOMS_WELCOME → COM5_REFUSE
```

Both are lawful.

```text
WELCOME != ADMIT
CUSTOMS != CONSEQUENCE
PORCH != INTERIOR
```

This is a bounded precursor to the real R3 receiver rather than a claim that R3 persistence is finished.

## 4. Fog Customs

A customs HOLD may become a Fog Case.

Fog records:

- what is known;
- what remains unknown;
- what question would reduce uncertainty.

It does not silently convert uncertainty into refusal.

```text
UNKNOWN != REFUSE
HOLD != ADMIT
QUESTION != VERDICT
```

This composes FogGlass with the Porch/Customs boundary.

## 5. Cultural Weather

Weather is a projection over observed receipts.

The first executable weather exposes:

- receipt counts by kind;
- counts by grammar;
- held/unresolved pressure.

It intentionally exposes **no rank, recommendation, score, or authorization**.

```text
WEATHER != RECOMMENDATION
FREQUENCY != VALUE
PRESSURE != AUTHORITY
```

This composes Groove Rooms / Haunted Toaster field pressure with real crossing receipts and creates the first anti-feed-shaped data surface.

## 6. Tradition

An admitted signed receipt may support a Tradition Trace.

The trace binds:

- source capsule;
- grammar ID;
- admitted receipt;
- descendant artifact;
- explicit variation.

It always states:

```text
ancestry_preserved = true
inherited_authority = false
```

This is the first small MEMENTO composition.

```text
UPTAKE != OWNERSHIP
DESCENDANT != ANCESTOR
ANCESTRY != AUTHORITY
```

## 7. Participation → Capacity proposal

Admitted participation may produce a **capacity proposal**.

It does not directly mint capability.

The proposal names:

- the admitted signed receipt;
- participant reference;
- proposed capability kind;
- local scope.

It also fixes:

```text
proposal_only = true
reputation_score = null
```

A refused crossing cannot produce a capacity proposal.

```text
PARTICIPATION != REPUTATION
PARTICIPATION != CAPABILITY
PROPOSAL != AUTHORIZATION
```

This is the Circle / BananaGram composition seam.

## 8. Sabbath / Jubilee Port

A world can declare one of three lifecycle motions:

- `REST`
- `RELEASE`
- `MORTALITY`

All preserve history.

All state:

```text
deletion_implied = false
successor_authority = fresh-decision-required
```

If material is explicitly offered for reuse, a license reference is required.

```text
REST != DELETE
RELEASE != PUBLIC DOMAIN
MORTALITY != HISTORY ERASURE
SUCCESSOR != INHERITED CROWN
```

This composes BananaSpork mortality/Sabbath with Jubilee release and reconstitution law.

## 9. Commuter Line

The Commuter Line is the influence graph made from witnessed crossings and receipts.

An edge records:

- source world;
- destination world;
- crossing ID;
- receipt ID when signed;
- local disposition;
- semantic effect.

It also exposes possible return routes from the crossing's declared return address.

The graph does not primarily answer:

> who follows whom?

It answers:

> what crossed, where, what happened locally, and where can a descendant return?

```text
ROUTE != AUTHORITY
EDGE != ENDORSEMENT
RETURN ADDRESS != RETURN OBLIGATION
```

## What remains deliberately unearned

Ecology Machine 001 does not yet prove:

- durable receiver state;
- restart reconstruction;
- duplicate-delivery idempotence;
- parent/payload artifact resolution;
- real HTTP or peer transport;
- discovery of remote porches;
- legal interpretation of licenses;
- human identity;
- generalized capability issuance;
- real external ecosystem participation;
- automatic grammar extraction from arbitrary media;
- R3–R13 completion.

The machine is a composition witness.

It exists to expose the next failures.
