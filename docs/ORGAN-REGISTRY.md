## Absorption rule

A donor mechanism enters reLATTE only through an explicit interface.

```text
SOURCE ORGAN
  ↓
owned contract / proof
  ↓
reLATTE adapter or shared primitive
  ↓
hostile tests
  ↓
bounded reuse
```

No copy of terminology, schema, or implementation silently transfers authority.

```text
REUSE != OWNERSHIP
COMPATIBILITY != AUTHORITY
IMPLEMENTATION != CANON
```
