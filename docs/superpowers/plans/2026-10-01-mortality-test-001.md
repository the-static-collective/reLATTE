# Mortality Test 001 — R12 Plan

## Goal

Kill one durable sovereign node and prove a fresh successor can be reconstituted from surviving attributable material without impersonation or inherited admission.

## Required proof

- predecessor builds durable R3 history;
- predecessor history is covered by an R11 receipt-set commitment;
- predecessor emits a signed R12 mortality seed referencing that checkpoint;
- two R7 mirrors retain every declared recoverable crossing;
- two peer archives retain the same content-addressed succession capsule;
- succession capsule includes signed predecessor historical receipts;
- all predecessor receipt signatures/key continuity verify;
- every recoverable crossing has historical predecessor RECEIVE evidence;
- delete predecessor receiver root and private key;
- delete one mirror;
- delete one peer succession archive;
- delete foreign Git witness;
- surviving mirror and succession archive remain sufficient;
- create successor with fresh world ID, receiver particular, and key;
- successor receives all recoverable crossings with no inherited admission;
- successor signs R12_SUCCESSOR_ACCEPTANCE under fresh key;
- predecessor receipts still name predecessor;
- successor receipts name successor;
- successor can later make a fresh independent ADMIT;
- same predecessor world/particular cannot be reused by the reconstitution helper.

## Non-collapses

```text
SUCCESSOR != PREDECESSOR
RECONSTITUTION != RESURRECTION
CONTINUITY != IDENTITY
ANCESTRY != AUTHORITY
PREDECESSOR ADMIT != SUCCESSOR ADMIT
SURVIVING ARTIFACT != INHERITED AUTHORITY
```

## Stop condition

Do not add successor election, legal ownership transfer, private-key recovery, journal resurrection, remote DR orchestration, quorum succession, or R13 claims.
