# Release Rule Hostile 001 — Plan

## Goal

Attack the independent release rule after R13:

```text
two materially different organ families
must cross one shared substrate
without donor-specific branches in core
```

## Donor families

### Daily Slice

- public chronological witness
- Markdown/document payload
- historical posture and non-authority claims

### Haunted Toaster

- deterministic media execution
- render receipt + MP4 payloads
- KEEP continuation claim and donor-local render authority

These are chosen because their domain meanings, payload shapes, and local consequences differ materially.

## Required proof

- one generic opaque-organ adapter implementation;
- no family enum;
- both donor families create valid signed crossings through the same function;
- both use declared kind `OPAQUE_ORGAN_ARTIFACT`;
- donor semantics remain signed opaque extension data;
- Daily Slice uses one Markdown payload;
- Haunted Toaster uses JSON + MP4 payloads;
- both travel through the same file transport;
- both travel through the same HTTP transport;
- same LocalReceiver implementation receives both;
- duplicate second-road delivery remains idempotent;
- owner-local law may ADMIT one and HOLD the other outside substrate branching;
- source-code tripwire rejects donor identifiers/vocabulary in adapter/protocol/transport/receiver;
- unknown third family crosses without a new enum;
- donor-claim mutation fails signature verification;
- payload mutation fails signature verification;
- descriptor sidecar is rejected;
- family-specific adapter-input sidecar is rejected.

## Non-collapses

```text
DONOR SEMANTICS != SUBSTRATE SEMANTICS
FAMILY != DISPOSITION
OPAQUE != UNBOUND
EDGE ADAPTER != CORE EXCEPTION
GENERIC != UNIVERSAL
```

## Stop condition

Do not use a green gate to claim universal applicability, production readiness, semantic compatibility with every donor, legal interoperability, or completion of still-open lower-level roadmap gaps.
