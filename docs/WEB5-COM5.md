# Web 5.0 / COM⁵ — The Five-Door Web

**Status:** working architectural shorthand / non-normative  
**Date:** 2026-10-01  
**Depends on:** [COM⁵ — The reLATTE Metabolism](COM5.md)

> **Web 5.0 is not a fifth centralized stack. It is a web that can be viewed through five metabolic doors.**

"Web 5.0" is used here as a project nickname for the COM⁵ application surface.

It is **not** a claim that reLATTE supersedes an industry-standard Web 1/2/3/4 sequence, and it does not require a new global network, browser monopoly, token layer, or universal runtime.

The useful idea is smaller:

> Any addressable particular may be encountered through five non-sovereign views: COMPOST, COMPOSE, COMPUTE, COMMUTE, and COMMUNE.

```text
                 [ particular ]
                 /    |    |    \
                /     |    |     \
        COMPOST  COMPOSE COMPUTE COMMUTE  COMMUNE
```

The doors are projections.

They do not alter the thing behind them.

```text
VIEW != SOURCE
VIEW != AUTHORITY
DOOR != CROSSING
PROJECTION != MUTATION
```

---

## 1. The web primitive changes from page to particular

The conventional web foregrounds a page or resource.

The COM⁵ view foregrounds an addressable particular and its attributable relations.

A page can still be a page.

A file can still be a file.

A person can still be a person.

A receipt can still be a receipt.

The five-door view asks different questions without forcing a single answer.

### COMPOST

What prior material remains available as substrate?

- revisions;
- residuals;
- superseded renderings;
- refused crossings;
- stale cuts;
- old receipts;
- failed experiments;
- unresolved fragments.

### COMPOSE

What declared relations involve this particular?

- parents;
- descendants;
- blends;
- assemblies;
- source references;
- organ composition;
- comparison structures.

### COMPUTE

What accountable consequences have been or may be produced under local law?

- verification;
- HOLD;
- ADMIT;
- REFUSE;
- RETURN;
- local execution;
- signed receipts.

### COMMUTE

How has the particular crossed boundaries while preserving declared invariants?

- Git;
- relay;
- removable media;
- local copy;
- peer transport;
- mirrored addressed bytes.

### COMMUNE

Where does the particular participate in shared life without collapsing participants?

- rooms;
- groups;
- projects;
- performances;
- traditions;
- collaborative artifacts;
- witnessed participation.

## 2. The browser becomes a room

The first UI primitive is intentionally simple:

> **Every focal particular gets five doors.**

```text
┌─────────────────────────────────────────────┐
│ PARTICULAR: crossing:T1                     │
├─────────┬─────────┬─────────┬───────┬───────┤
│ COMPOST │ COMPOSE │ COMPUTE │COMMUTE│COMMUNE│
├─────────┼─────────┼─────────┼───────┼───────┤
│ ...     │ ...     │ ...     │ ...   │ ...   │
└─────────┴─────────┴─────────┴───────┴───────┘
```

A door may be empty.

An empty door means:

```text
NO OBSERVATION PRESENT
```

not:

```text
ROLE IMPOSSIBLE
ROLE FALSE
HISTORY ABSENT
```

The browser must preserve fog.

---

## 3. Five doors, not five stages

The five-door browser must not imply:

```text
COMPOST → COMPOSE → COMPUTE → COMMUTE → COMMUNE
```

is a mandatory sequence for every object.

The loop is a metabolic grammar.

The room is a projection.

A focal subject may appear behind several doors at once.

```text
ONE PARTICULAR
  ├─ COMPOST observation
  ├─ COMPOSE observation
  ├─ COMMUTE observation
  └─ COMMUNE observation
```

Therefore:

```text
DOOR MEMBERSHIP != LIFECYCLE STATE
MULTIPLE DOORS != CONTRADICTION
EMPTY DOOR != NEGATION
```

---

## 4. Hyperlinks become typed roads

A normal hyperlink says approximately:

```text
here → there
```

reLATTE can preserve richer roads:

```text
source
  ↓
typed relation
  ↓
crossing identity
  ↓
carrier(s)
  ↓
receiver-local disposition
  ↓
receipt / residual / descendant
```

The Five-Door Web does not replace ordinary links.

It allows a link or crossing to carry inspectable ancestry and consequence where a domain chooses to provide it.

The crucial law remains:

> **The road may commute while the worlds diverge.**

A browser can verify that two routes delivered the same crossing without claiming that two receivers must render or admit it identically.

---

## 5. Local-first browsing

The Five-Door Web should remain useful when a cloud coordinator disappears.

A room may be reconstructed from locally retained observations and artifacts.

```text
CLOUD DOWN
!=
ROOM GONE

MISSING REMOTE OBSERVATION
!=
PERMISSION TO INVENT IT
```

Remote services may enrich discovery.

They do not own the focal particular or its local interpretation.

---

## 6. Shared rooms without shared minds

The COMMUNE door should make participation visible while preserving member sovereignty.

```text
ROOM != MEMBER
GROUP != MEMBER
PARTICIPATION != ABSORPTION
ADMINISTRATION != SOVEREIGNTY
```

A room may host many histories.

It need not manufacture one authoritative interior state.

---

## 7. First executable UI contract

The first bounded implementation is a Five-Door Room projection.

Input:

```text
focal subject
+
explicit COM⁵ observations
```

Output:

```text
five ordered doors
+
observations whose subject exactly matches the focal subject
+
count of observations about other subjects
```

It deliberately does **not** infer relation merely because another identifier appears in notes or evidence.

That keeps the first UI surface conservative.

```text
MENTION != RELATION
REFERENCE != MEMBERSHIP
DISPLAY != AUTHORITY
```

## 8. Web 5.0 compression

```text
WEB 1  browse
WEB 2  participate
WEB 3  verify / own / compose across decentralized systems
WEB 5  [working shorthand only]
       compost
       compose
       compute
       commute
       commune
```

The numbering is not the claim.

The five verbs are.

> **A web becomes more alive when it can preserve remains, form relations, produce local consequence, cross boundaries, and host participation without requiring everything to become one thing.**
